## 一、專案目標

《森之幻寵》是一款以魔法森林為背景的網頁互動遊戲。玩家透過召喚魔法蛋取得不同稀有度與屬性的萌寵，逐步完成圖鑑收藏，並利用重複召喚獲得的碎片進行升星與進化。

本專案希望達成以下目標：

1. 建立一款具有完整操作流程的網頁遊戲，而非單純的靜態展示頁面。
2. 設計 22 隻具有獨特外觀、屬性與背景故事的萌寵。
3. 整合召喚、圖鑑、養成、每日任務、成就與商店系統。
4. 使用 SVG 繪製角色，確保整體美術風格一致。
5. 支援電腦、手機與平板瀏覽器。
6. 使用瀏覽器本機儲存機制，保留玩家遊戲進度。

### 3.3 萌寵資料欄位

每隻萌寵應包含名稱、屬性、稀有度、造型類型、主要顏色、輔助顏色、個性、背景故事、星級、碎片數量、是否擁有，以及一般／進化形態等資料。

### 3.4 角色美術要求

- 角色必須使用 SVG 向量繪圖。
- 22 隻萌寵需要具有可辨識的不同造型。
- 同一角色的一般形態與進化形態須保持視覺關聯。
- 頭部、耳朵、身體、翅膀與尾巴不得出現明顯缺損。
- 圖鑑縮圖、養成室與主城展示應使用一致的角色造型。
- 未取得角色以剪影形式呈現。

其中 R 級風屬性角色「幸運四葉靈」採用四葉幸運草精靈的設計概念。

## 四、六大頁面功能需求

### 4.1 主城｜魔法森林

主城是玩家進入遊戲後的主要畫面，提供森林場景、萌寵展示與其他功能的入口。

功能需求：

- 依照裝置當地時間自動切換白天與夜晚森林背景。
- 白天時段為 06:00–17:59，夜晚時段為 18:00–05:59。
- 森林中央顯示玩家指定的萌寵。
- 點擊萌寵時，觸發跳動動畫與角色對話。
- 玩家可以從已擁有的萌寵中更換主城展示角色。
- 提供「前往召喚」快捷按鈕。
- 下方顯示三張資訊卡：魔法召喚、森林夥伴、今天的魔法。

### 4.3 圖鑑｜萌寵收藏

圖鑑提供全部 22 隻萌寵的收藏資訊。

功能包含收藏進度、角色預覽、已擁有與未擁有狀態、稀有度篩選、屬性篩選、角色詳細資料、前後角色切換，以及五星進化展示。

圖鑑排列規則： 優先依稀有度 SSR → SR → R → N 排列，同稀有度再依火 → 水 → 風 → 雷 → 光 → 暗排序。

點擊角色後，顯示左側大型 SVG 插畫及右側角色資訊。未擁有的角色以剪影顯示，已擁有角色則顯示名稱、屬性、稀有度、星級、個性與背景故事。

### 4.4 養成｜萌寵養成室

玩家透過收集碎片提高萌寵星級，最高可提升至五星。

| 升星階段      | 所需碎片 |
| --------- | ---- |
| 1 星 → 2 星 | 2    |
| 2 星 → 3 星 | 3    |
| 3 星 → 4 星 | 4    |
| 4 星 → 5 星 | 5    |

功能需求：

- 左側顯示玩家擁有的萌寵清單。
- 右側顯示選中萌寵的大型插畫與升星資訊。
- 顯示目前星級、下一星級所需碎片、專屬碎片、通用碎片及進度條。
- 可勾選「只顯示可升星萌寵」。
- 升星前須顯示確認視窗。
- 優先消耗專屬碎片，不足時以相同稀有度通用碎片補足。
- 達到五星後開放一般形態與進化形態切換。
- 保留玩家最後選擇的萌寵。

每日任務及成就均支援單項領取與全部領取。當存在可領取獎勵時，應顯示紅點提醒。

## 六、資料儲存規格

遊戲使用瀏覽器 `localStorage` 儲存資料，不需建立帳號或後端資料庫。

| 資料項目   | 儲存內容         |
| ------ | ------------ |
| 召喚石    | 目前餘額         |
| 召喚紀錄   | 累積召喚次數       |
| SSR 保底 | 距離上次 SSR 的抽數 |
| 萌寵收藏   | 已擁有的角色       |
| 萌寵星級   | 各角色目前星級      |
| 碎片資料   | 專屬碎片及通用碎片    |
| 展示設定   | 主城展示萌寵       |
| 進化設定   | 一般／進化形態      |
| 每日任務   | 完成、領取及日期     |
| 成就     | 累積進度及領取狀態    |
| 商店     | 當日免費禮包領取狀態   |
| 新手教學   | 是否已完成教學      |

資料更新後應立即儲存。重新整理或關閉瀏覽器再開啟時，遊戲須恢復既有進度。

需注意：`localStorage` 僅保存在對應瀏覽器與網站來源中，清除網站資料、更換裝置或改變網站網址，可能導致原有進度無法直接取得。

- 內容區域允許捲動，避免按鈕、卡片或文字被遮住。
- 不使用額外的白色底部裝飾牆。
- 移除左側選單最下方的「第五階段・森林商店」提示卡。

## 十二、開發技術與部署方式

本遊戲採用前端網頁技術，主要組成如下：

- HTML5： 建立頁面結構、按鈕、卡片與互動元素。
- CSS3： 控制配色、排版、響應式設計、動畫及捲動行為。
- JavaScript： 實作召喚機率、保底、角色收藏、碎片養成、任務與資料更新。
- SVG： 以向量方式繪製萌寵及進化造型。
- localStorage： 保存遊戲進度。
- GitHub Pages： 可作為靜態網頁的公開部署平台。

整體採用單一 HTML 檔案的形式，方便課堂展示、程式碼繳交與後續維護。

## 十三、專案成果摘要

《森之幻寵》以生成式 AI 輔助開發（Vibe Coding）的方式，完成一款具有六大頁面、22 隻萌寵、隨機召喚、保底機制、圖鑑收藏、碎片升星、五星進化、每日任務、成就及免費商店功能的網頁遊戲。

在美術設計方面，透過 SVG 向量插畫維持萌寵風格一致；在系統設計方面，利用 JavaScript 處理遊戲邏輯，並以 localStorage 儲存玩家進度，使遊戲能在不依賴後端伺服器的情況下運作。
